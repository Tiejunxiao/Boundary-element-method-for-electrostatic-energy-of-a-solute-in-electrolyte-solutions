# Boundary-element-method-for-electrostatic-energy-of-a-solute-in-electrolyte-solutions
This BEM folder contains fortran codes which  use the boundary element method (BEM) and  Debye-Hückel(DH) type response theory to 
evaluate the electric potential and  the electrostatic energy of a solute in an electrolyte.
The DH theory uses single DH response mode to evaluate  the  electrostatic energy.
The molecular Debye-Hückel(MDH)  theory in this study uses two DH-like response modes to evaluate the  electrostatic energy.

The "DA" folder contains  files for BEM calculation of diatomic solutes. 
The "TA" folder contains  files for BEM calculation of  linear triatomic solutes.
The "TAb" folder contains  files for  BEM calculation of  nonlinear triatomic solutes.
The "FA" folder contains  files for  BEM calculation of linear tetraatomic solutes.
The "FAb" folder contains  files for  BEM calculation of  nonlinear tetraatomic solutes.
The "FIA" folder contains  files for  BEM calculation of  pentaatomic solutes.
