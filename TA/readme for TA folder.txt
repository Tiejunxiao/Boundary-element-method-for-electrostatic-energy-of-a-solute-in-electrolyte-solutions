(1.0) About the file  "MDH.f "
The fortran code, entitled "MDH.f " , uses the boundary element method(BEM) and molecular Debye-Huckel(MDH) theory to calculate the electrostatic energy of a linear triatomic solute solvated  in an electrolyte solution.
The electrostatic response of the electrolyte solution is described by two DH-like response mode.
The two effective inverse Debye length of the solution are  k1=(0.5846+0.7673*i)/Angstrom and  k2=(0.5846-0.7673*i)/Angstrom. 
k1 and k2 are a pair of  conjugate complex numbers.
 The relative  dielectric constant 78 is used explicitly in the "MDH.f" file to evaluate the electrostatic energy. 

(1a)The  "MDH.f" file directly evaluate the electrostatic energy contribbution  of  one DH mode with k1=(0.5846+0.7673*i)/Angstrom . 
This electrostatic energy contribution is  a complex number, e.g.,  u1= c1 +c2*i. 
 The second DH mode with  effective Debye parameter k2=(0.5846-0.7673*i)/Angstrom would lead to
an electrostatic energy u2=  c1 +c2*i. Then the total electrostatic energy from two DH response modes  reads ue= u1+ u2= 2*c1= 2*Re(u1). 

The code "MDH.f" needs to be compiled  together with the LAPACK package to obtain an excutive file.

(1b)Four input files are needed for the BEM electrostatic energy calculation using "MDH.f " : 
the file "TA.crg" contains the location and  charge number of each atom of the complex solute
the file "TA.vert" contains the vertice information of the molecular surface
the file "TA.face" contains the face information of the molecular surface
the file "TA.curvature" contains the curvature information of the molecular surface.

(1c) Both the "TA.vert" file and "TA.face" file are generated with Sanner's msms code(e.g., https://csb.vanderbilt.edu/comp/soft/msms/) .
"TA.xyzr" is the input file for msms code.
The file "TA.curvature" is generated with the fortran code "curvature.f90".

(1d)The three parameters  used in the "MDH.f" file, namely " node, nedg, nele ", are related to the numbers of vertices, edges and faces of the molecular surface
generated by the msms code, respectively. 

(1e)For a solute with fixed solute geommetry but tunable site charges ,  the  "TA.vert", "TA.face"  and  "TA.curvature"  files keep the same 
while the  "TA.crg" needs to be modified according to the site charge numbers.

The "TA.crg"  files  depend on site charges (z1,z2,z3).
The following keys are used for simulations.
key        (z1,z2,z3)
TA1        (1,0,0)
TA2        (0,1,0)
TA3        (-1,0,1)
TA4        (-1,1,1)
TA5        (1,-1,1) 
When used for BEM calculation, please copy the content of the file "key.crg"  to the file "TA.crg" or modify the charge numbers of the "TA.crg" file.

(1.1) About the file  "DH.f "
The fortran code, entitled "DH.f " , uses the boundary element method(BEM) to calculate the electrostatic energy of a  solute solvated  in an electrolyte solution,
for a DH response mode with Debye parameter kD= 0.805 /Angstrom.
Only three input files ("TA.crg", "TA.vert", "TA.face" ) are  needed for the electrostatic energy calculation.

(2) About the file  "curvature.f90"
 The fortran code, entitled "curvature.f90", is used to calculate the Gaussian curvature and mean curvature of the molecular surface of a  triatomic solute.

Three input files ("TA.xyzr", "TA.vert" and "TA.face" ) are needed for the "curvature.f90" code.
The output file "TA.curvature" contains the curvature information( Gaussian curvature and mean curvature ) on the molecular surface. 

(3) About Sanner's msms code
Both the "filename.vert" file and "filename.face" file are generated with Sanner's msms code(e.g., https://csb.vanderbilt.edu/comp/soft/msms/) 
using the "filename.xyzr" file as input.
The  "filename.xyzr" file, which contains the location and hard sphere radius of the atoms of the complex solute.
e.g., for probe radius 1.00 Angstrom and vertice number density 2.0 vertice/Angstrom^2, 
one may use the msms command "./msms -if TA.xyzr -prob 1.00 -den 2.0 -of TA" to generate  "TA.vert" and "TA.face" with "TA.xyzr" as input.

If one want to use the above code to calculate the electrostatic energy of other solutes with different geometry and site charges,
then one needs to update the related input files.
